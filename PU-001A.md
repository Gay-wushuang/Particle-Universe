# PU-001A — Minimal NumPy NVE Core

## Scope

This implementation is limited to the PU-001A authorization: a three-dimensional, single-component, reduced-unit Lennard-Jones NVE core using Python, NumPy, float64, energy-shifted potential variant A, `rc=2.5`, periodic minimum images, and Velocity-Verlet.

It does not implement potential variant B, NVT/NPT, GPU execution, Taichi, JAX, Numba, neighbor lists, rendering, or a UI. N1a, N1b, N5, and the C group remain assigned to PU-001B and are not claimed here.

## Module boundaries

- `state.py`: validated particle state.
- `potential.py`: variant-A energy and analytic Newton-paired forces.
- `boundaries.py`: free analytic-test boundary and production periodic boundary.
- `integrator.py`: production Velocity-Verlet only.
- `initialization.py`: FCC, legal two-body states, and seeded Maxwell-Boltzmann velocities with center-of-mass momentum removal.
- `diagnostics.py`: energy, temperature, and momentum definitions.
- `simulation.py`: initial/step force counters, trajectory sampling, metadata, and run orchestration.
- `__main__.py`: deterministic JSON-producing command-line entry point.

## Commands

Run the fast deterministic suite:

```text
python -m unittest discover -s tests -v
```

Run and archive the numbered PU-001A acceptance metrics:

```text
python scripts/run_pu001a_acceptance.py --output artifacts/pu-001a-acceptance.json
```

Run a small FCC trajectory:

```text
python -m particle_universe --cells 3 --density 0.8 --temperature 1.0 --seed 42 --dt 0.002 --steps 10 --output run.json
```

Every run records thermodynamic samples, the trajectory, separate initial/step force-evaluation counts, the explicit seed, physical parameters, boundary legality, environment, timestamps, and drift diagnostics. JSON serialization rejects NaN and infinity.

## PU-001A acceptance mapping

- M1: analytic force versus central finite-difference negative energy gradient.
- M2: two-body analytic force at the five frozen separations.
- M3: shifted energy uses the number of interacting pairs, not particle count.
- N3: `L/2 <= rc` is rejected and the legal minimum image is checked.
- N4: one initial force evaluation is separated from exactly one evaluation per completed Velocity-Verlet step.
- R1: repeated fixed-seed trajectories and energy sequences are bit-identical.
